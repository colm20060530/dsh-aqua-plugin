# Aqua v1.4.3

出厂默认值改成实际在用的观感，新装即所见。

## 默认值

| 设置项 | 默认值 |
| --- | --- |
| 玻璃模糊度 | 3 px |
| 磨砂度 | 6 % |
| 视频模糊度 | 2 px |
| 视频亮度 | 35 % |
| 背景亮度 | 46 % |
| 背景 | 壁纸（内置视频） |
| 粒子鲸鱼 / 小鱼 / 网格交互 | 关 |
| 鼠标辉光 / 悬停下压 | 关 |

## 新增

- **设置里「恢复默认」按钮**：通用设置 → Aqua 面板顶部，一键把所有玻璃参数写回出厂值（总开关不动，不会把皮肤关掉）。
- **弹层保留玻璃质感、同时保证可读**：菜单 / 下拉 / 斜杠指令列表 / 模型选择这些弹层之前直接复用玻璃旋钮，太透导致底下正文透上来、文字像重影；但做成不透明面板又等于没有玻璃。现在按轨迹面板的程度处理 —— 底色随「磨砂度」变化（深色 63% → 75%）+ 模糊半径为「玻璃模糊 + 10px」+ 独立边框投影；弹层里的浮动详情对话框（轨迹工具详情）原先写死 `blur(50px)` 和固定底色、两个旋钮都够不着，现在同样跟随旋钮。
- 设置里 warning emoji（⚠️）中英文四处全部移除。

## 修复

- **磨砂度不再把深色模式拖暗**：深色玻璃底色原本是 `color-mix(#22262f, 50% × 磨砂系数)`，深色底叠更高不透明度只会更黑 —— 磨砂拖到 70 多时输入框几乎变成一块深色板。现在深色底改为浅石板色 `#8b98b0`、不透明度收在 14%~28%，磨砂只增加「乳白感」；聊天列底色从 50%~67% 降到 30%~43%，并去掉聊天列上的实时模糊（全屏每帧多一遍过滤，只让视频更糊更闷）。
- **玻璃模糊度 / 磨砂度失效**：1.4.1 的性能优化在壁纸模式下给所有元素加了 `backdrop-filter: none !important`。模糊度只写 `--dsh-aqua-blur`，磨砂度只写 `--dsh-aqua-frost`，两个旋钮都靠 `backdrop-filter` / `color-mix` 落地，所以拖动完全没反应。现在去掉这条一刀切规则，渲染预算交给原有的精确规则（行内 code/pre、设置里的按钮与分段项、弹窗蒙层）。
- **装饰与悬停效果首装也是关**：五个开关的读取函数原来「没有记录就算开」，新装或新 profile 仍会打开粒子鲸鱼、小鱼、网格交互、鼠标辉光和悬停下压。读取默认值改为关。
- **视频亮度首装就是 35**：`SETTINGS_DEFAULTS` 里原来还留着 50，`readSetting` 缺记录时回退到它；现在两处默认字面量统一为 35。
- **设置架构版本**：`cordis.patch.yml` 的插件行可写 `schema`，默认值调整后老 profile 会一次性重置 `dsh.ui-aqua.*`（保留总开关）。迁移在 `apply(ctx, config)` 内执行；写在模块顶层引用 `ctx` 会让客户端条目 import 失败（`web boot: 1 entry did not activate`）。
- 存储不可用时背景回退到壁纸、壁纸回退到内置视频。

## 升级

替换 `lib/client.js` 与 `package.json` 后重启应用，或重新执行安装脚本：

```powershell
pwsh -File scripts/install.ps1
```

已经存过设置的 profile 不会被覆盖：升级后到设置里点一次「恢复默认」即可回到上表的出厂值。
